# System Design Learning Repository

This repository is a day-wise learning journey through core system design concepts. It is meant to help you build understanding step by step, starting from fundamentals like requirements, scalability, and bottlenecks, then moving into caching, databases, messaging, microservices, and distributed system design patterns.

## Main Purpose Of This Repo

The main reason for this repository is to provide a structured, practical, and progressive path for learning system design. Each `Day-XX` folder focuses on one concept or a closely related set of concepts so you can study the topic in sequence without feeling lost.

## How To Use This Repo

1. Start from `Day-01` and move forward in order.
2. Read the `Readme.md` inside each day folder first to understand the concept.
3. Go through any supporting notes or extra files available in that folder.
4. Use the `Practise_Questions` folder to revise and test your understanding.
5. Revisit later days after finishing earlier ones, since many topics build on previous concepts.
